Sobre o Sistema

Este dashboard representa a interface de um sistema de monitoramento ambiental de sala de aula. Nesta etapa os dados são simulados em JavaScript; futuramente serão substituídos por leituras reais de um ESP32 com os sensores planejados, sem necessidade de reconstruir a interface.
